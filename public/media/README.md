# Media

Put images and 3D models here.

- `projects/<slug>/` — per-project covers, gallery photos, and `.glb` models
- `about/` — portrait / about photo
- `home/` — hero image

Example paths in JSON:

- `/media/home/hero.jpg`
- `/media/about/portrait.jpg`
- `/media/projects/fog-collector/cover.jpg`
- `/media/projects/fog-collector/photo-1.jpg`
- `/media/projects/fog-collector/model.glb`
